# Points à confirmer

Périmètre de lecture : manuel utilisateur 1.1, cartes 1.1 et 1.2, code officiel v1.0.2. La comparaison porte sur les sources. Aucune mesure sur un exemplaire physique n’a été effectuée.

| Sujet | Ce que les sources établissent | Ce qui reste ouvert et conséquence pour la notice |
|---|---|---|
| Profondeur de montage | Le plan donne une façade de 50,5 × 128,5 mm et les vues de montage montrent les entretoises. | Profondeur totale derrière la façade, nappe installée, absente des cotes. Mesurer un exemplaire assemblé pour donner une cote de boîtier. La 3D pourra présenter l’assemblage sans promettre cet encombrement. |
| Durée de Gate par CV | Le manuel p. 5 la marque comme non implémentée puis en décrit le comportement. En v1.0.2 la touche 0 est assignable, le code lit le CV et interpole la durée. | La fonction est présente dans ce code. La version installée sur un exemplaire donné et la réponse mesurée restent à vérifier. L’objectif nominal annoncé est une course de 5 V. |
| Retour au jeu libre | Le manuel p. 2 annonce environ une seconde après retrait de Trig. Le code compte 10 000 passages à environ 4,8 kHz par canal, soit environ 2,1 s dans la condition de retour. Un signal maintenu haut assez longtemps peut aussi satisfaire cette condition. | Chronométrer le retour sur la version installée. Le pas à pas indiquera un retour automatique après un bref délai. |
| Persistance du legato | Le legato fait partie de l’état enregistré. Dans UI.ino la bascule Shift + 7 change le drapeau sans relancer elle-même la minuterie de sauvegarde. | Vérifier un redémarrage après cette seule action, une fois la minuterie précédente expirée. Éviter de garantir qu’attendre 10 s après cette seule bascule suffise. |
| Rejet de note et transposition combinés | Les algorithmes renvoient une valeur spéciale pour une note ignorée ou une gamme vide. Core.ino ajoute ensuite la transposition sur une valeur 8 bits avant de tester la plage de sortie. | Tester Skip et une gamme vide avec transposition positive. Le comportement décrit pour Skip sera démontré à transposition nulle. |
| Limites électriques garanties | Les guides donnent des valeurs typiques de consommation, de tension et de seuil. Le guide 1.2B indique environ 9 V au niveau haut de Gate et un seuil de Trig inférieur à 1 V. | Le courant maximal par rail et les tensions maximales absolues admissibles sur les prises ne sont pas spécifiés. Les plages de fonctionnement ne serviront pas de limites de protection. |
| Exemplaire DIY | La révision 1.1 a fait l’objet d’un correctif recommandé sur les Trig. La révision 1.2 l’intègre. L’auteur précise que D6 doit être omise sur toutes les révisions. | L’application des modifications sur un exemplaire particulier demande son inspection. Le guide d’installation utilisera les repères de polarité du module et du bus. |
